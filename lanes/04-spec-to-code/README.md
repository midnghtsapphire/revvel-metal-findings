# 04 — spec-to-code

Discipline for the missing label. This lane holds methods that turn a finished research packet into `wr:code` without a human remembering.

Seed idea (trial, not a vendor): after `research:complete`, a grammar-checked classifier writes exactly one of `{wr:code, spec-approved, blocked}` onto the issue. No prose. Schema in this repo once the first trial runs.
